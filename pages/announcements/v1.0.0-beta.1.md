# v1.0.0-beta.1

This is the first public beta of **tviem**, a lightweight, type-safe TypeScript SDK for the TRON blockchain.

```bash
npm i @tronweb3/tviem
```

Requires Node.js 22+. TypeScript 5.4 or later is an optional peer dependency.

## Highlights

### Clients and transport

- `createPublicClient`, `createWalletClient`, and `createClient`, with the `http()` transport covering TRON's fullnode, solidity, and event HTTP APIs.
- Built-in chains: `mainnet`, `shasta`, and `nile`, plus `defineChain` for custom networks.

### Public actions

`getBalance`, `getAccount`, `getAccountResources`, `getBlock`, `getNowBlock`, `getChainParameters`, `getTransaction`, `getTransactionInfo`, `getLogs`, `readContract`, `triggerConstantContract`, `estimateEnergy`, `getSignWeight`, `getApprovedList`, and `waitForTransactionReceipt`.

### Wallet actions

Each action is standalone and tree-shakable.

- **Transfers:** `sendTrx`, `sendTrc10`
- **Contracts:** `writeContract`, `deployContract`, `clearAbi`, `updateSetting`, `updateEnergyLimit`, and `getContract` — a typed contract instance that includes `getEvents`
- **Staking v2 and resources:** `freezeBalanceV2`, `unfreezeBalanceV2`, `unfreezeBalance`, `cancelAllUnfreezeV2`, `withdrawExpireUnfreeze`, `delegateResource`, `undelegateResource`
- **Governance:** `voteWitness`, `applyForSr`, `updateWitness`, `updateBrokerage`, `withdrawBalance`, `createProposal`, `voteProposal`, `deleteProposal`
- **TRC-10 and exchanges:** `createToken`, `updateToken`, `purchaseToken`, `exchangeCreate`, `exchangeInject`, `exchangeWithdraw`, `exchangeTransaction`
- **Accounts and permissions:** `createAccount`, `updateAccount`, `setAccountId`, `accountPermissionUpdate`, `multiSign`
- **Signing and broadcasting:** `signTransaction`, `signMessage` (TIP-191), `signTypedData` (TIP-712), `broadcastTransaction`, `broadcastHex`

### Trustless local signing

- Before signing, the signer checks that the `txID`, `raw_data`, and `raw_data_hex` all agree, so blind signing is impossible by construction.
- Transactions and typed data are snapshotted before validation.
- Responses from the node are checked against the request. A tampered block raises `BlockTamperedError`, a receipt must match the requested transaction, and multisig responses are checked against what was sent.

### Accounts

Available from `@tronweb3/tviem/accounts`:

`privateKeyToAccount`, `mnemonicToAccount`, `hdKeyToAccount`, `toAccount`, `generatePrivateKey`, and `generateMnemonic`. Bare private keys are accepted wherever an account is expected.

### Utilities

Available from `@tronweb3/tviem/utils`:

- **ABI:** Encoding, decoding, and inspection, including TRON's `trcToken` type. Ambiguous overloads are rejected rather than guessed.
- **Addresses:** Base58Check (`T…`) and hex conversion, plus CREATE2 address derivation.
- **Units:** Conversion between SUN (6 decimals) and TRX.
- **Hashing and signatures:** TIP-191 and TIP-712.
- **Transactions:** Protobuf serialization with SHA-256 transaction IDs.
- Native `BigInt` throughout. No BigNumber library is used.

### Types and packaging

- Argument and return types are inferred from `as const` ABIs and TIP-712 typed data via `abitype`.
- The package ships as tree-shakable ESM and CJS and sets `sideEffects: false`.
- Entry points: `.`, `./accounts`, `./actions`, `./chains`, and `./utils`.
- Small, audited dependency set: `@noble/curves`, `@noble/hashes`, `@scure/base`, `@scure/bip32`, `@scure/bip39`, and `abitype`.
